# Burbujeo (Bubble Sort)

Recorre repetidamente la lista, compara elementos adyacentes y los intercambia
si están en el orden incorrecto. Las "burbujas" de elementos más grandes se
mueven hacia el final. Optimización: se detiene si no hubo intercambios en una
pasada completa. Es estable e in-place.

```bash
go run main.go
```
